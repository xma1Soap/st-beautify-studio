# 酒馆美化工坊（ST Beautify Studio）

给 SillyTavern 做角色卡和美化的工具，面向不会写代码的新人。有两种模式，在左上角切换：

## 现在能做什么

### MVU 角色卡（默认）

不用写代码，做一张带变量和状态栏的 MVU 角色卡（新版 MVU：zod 变量结构 + JSONPatch 更新）。

- 变量：左边加数字 / 文字 / 是否 / 选项 / 列表 / 分组 / 表格，或者从「＋ 模板」里挑一组现成的（时间地点、好感度、物品栏、任务、人物关系、角色状态、跑团属性……）；数字可以设范围和阶段（比如好感度 40 以上叫「朋友」）
- 每个变量写「什么时候变」，工具自动整理成给 AI 的规则和输出格式
- 状态栏：「状态栏」页里把组件（卡片、横排、网格、每项一张、标签页、折叠块、文字、变量值、进度条、分隔线、图片、按钮、菜单）拖到右边画布上自己摆，变量也能直接从左边拖过去；点中任何东西都能改颜色、渐变、圆角、边框、阴影；8 套配色一键换。不想摆就用自动排版
- 形状和摆放：组件可以切成多边形（切角、六边形、盾牌、旗帜、宝石、箭头、飘带、斜边、菱形），在画布上拖点改形状、点边加点、双击删点；框里选「自由摆放」后拖到哪就在哪，拖边角改大小，会吸附到框边、中线和旁边组件，消息变窄（手机）时整块等比缩小；玩家可以点选组件，选中时换一套颜色
- 进度条有四种样子：一条、分格、圆环、一排符号（★★★☆☆）；图片可以用链接或从电脑选，也能跟着变量换（比如不同表情配不同立绘）
- 更多样子：渐变文字、渐变边框、发光 / 描边这类文字效果、8 种字体、图标库；动效（呼吸、浮动、心跳、消息出来时浮上来、进度条从 0 长出来、鼠标放上去变大）；6 套一键风格（简洁、古风、赛博、可爱、暗金、玻璃）和 5 种现成排版（分页、折叠、紧凑、头像加信息、收成一行）；格式刷能把一个组件的样式贴到别的组件或所有同类上
- 互动：按钮可以打开修改面板、显示 / 藏起别的组件、切换标签页、往输入框里填字；菜单里能放按钮和子菜单
- 按数值变：变量值和进度条能按数值换颜色（可以慢慢过渡）、图标和后面的字（比如血量低于 30 变红并写「危险」）；能显示和上一楼比是涨了还是跌了（↑↓ 或 +3）；空的列表可以整块藏起来
- 数字怎么写：保留几位小数、每三位加逗号、除以一个数（配合写「万」）、按范围算成百分比，或者拆成单位（1金 5银 7铜、2天 3小时）
- 开场白：每条开场白可以有自己的初始值（比如备选开场白是晚上开始、钱更多），导出时自动写进那条开场白里
- 玩家改变量：在「角色卡」页允许后，给变量勾上「玩家可改」，再在状态栏上放一个「修改按钮」，玩家就能在聊天里直接改这些变量（比如跑团卡卡关时调一下数值）
- 预览：右边直接看到状态栏；「试试不同数值」里拖滑块看状态栏在别的数值下的样子；「模拟 AI 回复」里贴一段 AI 的回复（也能连着贴好几条，一条接一条算），能看到变量怎么变、哪条更新会被 MVU 拒绝
- 纯文字状态栏：「状态栏」页最上面切到「纯文字」，就只是几行「名字：值」，不跑脚本，最简单最稳；可以选显示哪些变量、改标题和配色。只显示在最新一条回复下面（酒馆助手的变量宏读的是最新的数值）
- 进阶：「进阶」页能看到工具写进卡里的所有内容（世界书、脚本、正则和状态栏代码）；变量更新规则和输出格式可以手动改；状态栏可以自己写 CSS，也能给组件起类名单独改
- 导出：「导出角色卡」得到一张 PNG 角色卡，在酒馆「导入角色」里直接用（需要装酒馆助手）；卡里的世界书、正则、脚本都自动写好。导出前会检查变量设置、开场白的初始值、状态栏用到的变量还在不在、手改过的规则是不是过时了
- 只导出 MVU 部分：已经有角色卡、只想加上变量和状态栏的话，在「进阶」页最上面下载世界书和正则，按说明把两个脚本复制进酒馆助手
- 导入：把别人做的 MVU 卡拖进来，工具会读出变量；原卡里其它内容导出时原样保留
- 保存：工程文件 `*.MVU卡工程.json`；导出的卡里默认也藏一份，拖回工具就能接着改

### 正则美化

给纯文字的 AI 回复做美化正则。

- 新建有三种：「手写代码」自己写；「在画布上做」用和状态栏一样的画布摆，AI 写的「名字：内容」按名字填进去（不管顺序、缺了也行），「给 AI」页有能复制的格式说明；「解析型面板」见下面
- 解析型面板：AI 分段写的战况、结算（`{战况总览}` 或 `【战况总览】` 起一段，下面 `|…|` 一行一条），变成能折叠的彩色面板。每段设图标、颜色、其他写法（繁体）、默认展开还是收起；行规则把「HP 30/100」画成血条（低于多少 % 变色）、「回合: 3」画成标签、「力12」画成属性块，还能给关键词、骰子、数字上色。改完复制格式说明给 AI 就行
- 识别成面板：别人写的战斗面板这类前端卡，点「🧩 识别成面板」，工具认出它的分段表、血条阈值和颜色、字段名、属性和配色，做成一条能直接改的解析型面板（原来那条先停用，不删）
- 点选修改：预览上方「✎ 点选修改」打开后，点卡片里的元素就能改文字、颜色、背景、字号、边距、边框、圆角和形状，按 ↑↓ 或直接拖动换位置，都写回正则代码（前端卡片里的点不进去，用下面的换配色或 AI 助手）
- 换配色：「替换内容」页的「🎨 换配色」列出代码里用到的所有颜色（前端卡片里的也算），能一个个换，也能整体转到赤橙金绿青蓝紫粉、拖色相和鲜艳度，或者亮暗反转；灰色和黑白不跟着转
- 导入：把正则 JSON、预设、角色卡 PNG、工程文件拖进窗口，或点「导入正则」
- 编辑：「替换内容」页用代码编辑器改 HTML；「正则设置」页改名称、查找正则、修剪、作用范围、选项、宏、深度，并显示每处匹配和捕获组
- 预览：按酒馆的顺序执行正则；```html 代码块按酒馆助手的方式渲染成卡片；可切换 📱 手机（360 / 390 / 430 宽）和 🖥 电脑
- 测试消息：自动按正则生成能命中的示例文本
- 保存：工程文件 `*.美化工程.json`（Ctrl+S / Ctrl+Shift+S / Ctrl+O）；关掉程序也会自动暂存，内嵌大图也存得下
- 撤销 / 重做：顶栏按钮或 Ctrl+Z / Ctrl+Y
- 导出：「导出当前」导出单条，「导出全部」导出成数组，都能直接在酒馆「正则 → 导入」里用

### 两种模式都有

- ✦ AI 助手：右边的面板接 OpenAI 兼容接口（填地址、密钥、模型），用对话改美化。AI 改的是一份草稿，改完列出改了哪些地方，点「应用」才生效，也能撤回；内置酒馆美化的写法指导，可以加自己的，也能导入酒馆的对话补全预设。密钥只存在这台电脑上，不进工程文件，也不进导出的卡
- 简易 / 进阶：顶栏切换。简易模式藏起字体、内边距、阴影、动效、类名、自己写 CSS 这些不常用的设置

两种模式的预览都和工具本身隔开：导入别人的卡、预览里跑的脚本读不到你存在工具里的工程，也碰不到电脑上的文件。卡片里用浏览器存储记的东西只在这次预览里有效。

## 下载和使用

有三种用法，功能一样：

| 版本 | 怎么拿到 | 适合 |
|---|---|---|
| 网页版 | 打开 `https://xma1soap.github.io/st-beautify-studio/`（需要先开启 GitHub Pages，见下） | 不想装软件 |
| 单文件网页版 | 下载 `st-beautify-studio-web.html`，双击用浏览器打开 | 发到群里给别人用、离线用 |
| 桌面版 | 下载 `st-beautify-studio-portable.exe`（免安装）或 `*-setup.exe`（安装包） | 常用、要直接存文件到电脑上 |

单文件网页版和桌面版都在 GitHub 的 **Actions** 页面：点最近一次成功的「桌面版（Windows）」，拉到底部的 Artifacts 下载 `windows`。推送 `v` 开头的标签（比如 `v0.2.0`）时还会自动建一个草稿版本，在 **Releases** 页面确认后发布。

网页版和单文件版保存时会下载文件，没法像桌面版那样直接覆盖原文件。

### 开启网页版

仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**，然后往 `main` 推送一次（或在 Actions 页面手动运行「网页版」）。

GitHub 免费账号的**私有仓库**开不了 Pages，要么把仓库改成公开，要么升级 GitHub Pro。开了之后网页是公开的，知道链接的人都能打开。

## 自动构建

| 构建 | 什么时候跑 | 产出 |
|---|---|---|
| 网页版（`.github/workflows/web.yml`） | 每次推送 | 检查能否构建、单文件网页版；`main` 上且已开启 Pages 时发布网页 |
| 桌面版（`.github/workflows/desktop.yml`） | 推送到 `main`、推送 `v*` 标签、手动运行、或其它分支提交说明里带 `[打包]` | Windows 免安装 exe、安装包、单文件网页版 |

私有仓库的 Windows 构建按 2 倍计时，所以桌面版不是每次推送都打包。

## 开发

需要 Node 22.22+ 或 24.15+（更早的版本也能用，只是 `npm ci` 会对测试用的依赖报 EBADENGINE 警告）、Rust（stable）。在 Windows 上打包还需要 VS Build Tools（C++）。

```bash
npm install
npm run dev            # 只在浏览器里跑界面：http://localhost:1420
npm run build:single   # 单文件网页版：dist-single/index.html
npm test               # 自动测试
npx tauri dev          # 桌面窗口 + 热更新
npx tauri build        # 打包
```

本地打包结果：

- 免安装 exe：`src-tauri/target/release/st-beautify-studio.exe`
- 安装包：`src-tauri/target/release/bundle/nsis/*.exe`

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/mvu/` | MVU 卡：变量树、zod 变量结构、世界书和正则生成、状态栏（含现成排版、风格、图标库）、模拟更新、整卡导入导出、变量模板 |
| `src/components/mvu/` | MVU 卡界面：变量树、变量设置、状态栏画布和设置、角色卡页、预览和模拟 |
| `src/cardStore.ts` / `src/cardActions.ts` / `src/barActions.ts` | MVU 卡的状态（撤销重做、自动暂存）、菜单操作、状态栏的增删挪 |
| `src/lib/engine.ts` | 正则引擎（照搬酒馆的执行逻辑）、示例文本生成 |
| `src/lib/builder.ts` / `src/regexBuilder.ts` | 在画布上做的正则：生成查找正则和前端卡片，排版藏在卡片的注释里 |
| `src/lib/panel.ts` / `src/panelScript.ts` | 解析型面板：设置、生成卡片、给 AI 的格式说明、从现成的卡里识别 |
| `src/lib/htmlEdit.ts` / `src/lib/palette.ts` | 点选修改（读懂 HTML、改 style 和文字、挪位置）和换配色 |
| `src/ai/` | AI 助手：接口、工具、草稿和改动对比、美化指导、预设导入 |
| `src/lib/render.ts` | 预览页面：消息气泡、前端卡 iframe、酒馆助手接口的简单模拟 |
| `src/lib/importer.ts` | 读取各种文件里的正则、导出格式 |
| `src/lib/png.ts` | 读写 PNG 角色卡里的数据 |
| `src/lib/files.ts` | 打开 / 保存文件（桌面版走系统对话框，浏览器里走下载） |
| `src/store.ts` | 正则美化模式的状态和自动暂存 |
| `src/components/` | 正则美化界面：顶栏、正则列表、编辑器、预览 |
| `src-tauri/` | 桌面外壳（Rust）：打开 / 保存对话框，只能读写用户在对话框里选过的文件 |
